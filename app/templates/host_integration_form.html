Authentication

Run these commands once in the server console, then use root and the root password below.

mkdir -p /etc/ssh/sshd_config.d
cat > /etc/ssh/sshd_config.d/99-outlaws-bootstrap.conf <<'EOF'
PermitRootLogin yes
PasswordAuthentication yes
EOF
sshd -t && systemctl restart ssh
