# Roadmap

Current technical baseline: **v0.15.0+**. Current release line: **v0.18.x**.

## Near-Term

- Continue product hardening and full security review.
- Continue provider reliability work for firmware and application checks.
- Maintain mobile usability without regressing desktop/tablet layouts.
- Keep installer, updater, backup/restore and documentation aligned with the supported baseline.

## Later

- Additional notification channels such as WhatsApp and Telegram.
- Disk trend/history where it adds operational value.
- Proxmox integration.
- Developer Tools for safe simulation of updates, failures and demo states.
- Docker distribution after the core installer/updater path is considered mature.
- Revisit optional visual themes/color treatments only after the Classic interface remains internally consistent and stable.

Historical pre-v0.15.0 compatibility work is intentionally outside the roadmap.
