# Contributing

The contribution workflow is intentionally conservative while the Device Profile format is being established.

- Device Profiles must be declarative YAML only.
- Use official vendor sources where possible.
- Do not include executable code, credentials, local/private URLs or personal data.
- New profiles must validate against the current schema and produce a deterministic catalog.
- Maintainer review is required before a profile becomes part of the trusted catalog.

Broader community contribution and licensing terms will be defined before public submissions are actively invited.
